// 傳奇篇章

三大傳奇，串起整個漫威宇宙。

以下依階段整理漫威影視宇宙的電影、影集與動畫影集，並依傳奇篇章分成三個部分。

01 // 無限傳奇

第一至第三階段

從《鋼鐵人》開始，到《蜘蛛人：離家日》為止，共 23 部電影，《復仇者聯盟：終局之戰》為無限傳奇的重要終章。

02 // 多重宇宙傳奇

第四至第六階段

影集與動畫影集加入陣容，目前共收錄 17 部電影與 23 部影集（含動畫影集），其中包含尚未上映的作品。
